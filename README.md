# SITCON Camp 2026 Publishing Poster

Standalone 16:9 publishing poster for camp publishing sites.

## Files

- `index.html` - HTML/CSS source poster design
- `camp-publishing-poster.png` - rendered 1920x1080 PNG

## Rendering

Install dependencies once:

```sh
pnpm install
```

Render a PNG:

```sh
pnpm render
```

Render a compressed JPEG under 100 KB:

```sh
pnpm render --compress
```
